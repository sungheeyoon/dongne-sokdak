# UI v2 제품·비주얼 계약

_Status: 검토 대기 (이슈 #14) · Last verified: 2026-08-11_

동네속닥 주민용 화면의 제품·비주얼 계약입니다. 후속 UI 이슈(#15–#20)의 구현자가 별도 해석 없이
작업할 수 있도록, **사용자에게 보이는 것**만 확정합니다. 파일 구조·컴포넌트 분해 방식은 고정하지 않습니다.

레퍼런스 레이아웃(1440px / 390px, 9개 화면): [`UI_V2_REFERENCE_LAYOUTS.md`](./UI_V2_REFERENCE_LAYOUTS.md)

---

## 0. 확정된 방향

| 항목 | 결정 | 근거 |
| --- | --- | --- |
| 브랜드 색 | 로고의 코발트 블루를 `brand`로 계승, 중성색은 따뜻한 계열 | 로고(말하는 파란 핀)와의 연속성을 지키면서, 차가운 슬레이트 중성색이 만드는 범용 블루 템플릿 인상을 제거 |
| 데스크톱 홈 | 상단 전폭 지도 + 하단 3열 제보 목록 | 현행 구조를 유지하되 높이·여백·카드 리듬을 계약으로 고정 |
| 모바일 홈 | **제보 피드가 기본 화면**, 지도는 명시적 전환 | 이슈 #16 |
| 글꼴 | Pretendard Variable 셀프호스팅 | 한글·라틴·숫자를 한 패밀리로 처리, OS별 우연한 fallback 제거 |
| 관리자 화면 | 토큰은 공유, 셸은 분리 | 토큰 작업이 관리자에도 자동 반영되면서 업무용 정보 밀도는 별도로 유지 |
| 컬러 스킴 | v2는 **라이트 모드만** 지원 | 다크 모드는 미결정 항목(§10)으로 이월 |

## 1. 색상 토큰

의미 기반 토큰만 사용합니다. 구현에서 `gray-*`, `blue-*`, `red-*` 같은 팔레트 유틸리티를
화면 코드에 직접 쓰지 않습니다.

### 1.1 기본 토큰

| 토큰 | 값 | 용도 |
| --- | --- | --- |
| `background` | `#FBFAF8` | 페이지 바탕 |
| `surface` | `#FFFFFF` | 카드·다이얼로그·헤더 등 올라온 면 |
| `surface-muted` | `#F2EFEA` | 보조 채움(필터 트랙, 스켈레톤 바탕, 비활성 면) |
| `foreground` | `#1A1815` | 본문·제목 |
| `muted-foreground` | `#6B6660` | 보조 텍스트, 메타데이터 |
| `border` | `#E7E3DD` | 구분선, 카드 테두리 (장식용) |
| `border-strong` | `#948A7C` | 입력·컨트롤 경계 (**컨트롤을 식별하는 유일한 수단일 때 필수**) |
| `brand` | `#1E52E0` | 기본 행동, 활성 상태, 링크 |
| `brand-hover` | `#1A47C4` | brand 요소 hover |
| `brand-pressed` | `#163CA8` | brand 요소 active |
| `brand-subtle` | `#EDF1FE` | brand 계열 옅은 채움 |
| `brand-foreground` | `#FFFFFF` | brand 위 텍스트 |
| `info` | `#2563EB` | 정보 안내 |
| `success` | `#2E7D5B` | 성공, 해결됨 |
| `warning` | `#8A5200` | 주의, 처리중 |
| `danger` | `#C1352B` | 오류, 파괴적 행동 |
| `ring` | `#1E52E0` | 포커스 링 |
| `scrim` | `rgba(26,24,21,0.48)` | 모달 뒤 오버레이 |

### 1.2 대비 검증 (WCAG 2.1)

실측값입니다. AA 기준: 일반 텍스트 4.5:1, 큰 텍스트(19px+ bold / 24px+) 3:1, 비텍스트 3:1.

| 조합 | 대비 | 판정 |
| --- | --- | --- |
| `foreground` on `background` | 16.98:1 | AAA |
| `foreground` on `surface` | 17.72:1 | AAA |
| `muted-foreground` on `background` | 5.45:1 | AA |
| `muted-foreground` on `surface` | 5.68:1 | AA |
| `muted-foreground` on `surface-muted` | 4.96:1 | AA |
| `brand` on `surface` | 6.29:1 | AA |
| `brand-foreground` on `brand` | 6.29:1 | AA |
| `danger` on `surface` | 5.51:1 | AA |
| `success` on `surface` | 5.00:1 | AA |
| `warning` on `surface` | 6.39:1 | AA |
| `info` on `surface` | 5.17:1 | AA |
| `border-strong` on `background` | 3.25:1 | AA (비텍스트) |
| `border` on `background` | 1.23:1 | 장식 전용 — 컨트롤 경계로 쓰지 않음 |

> `warning`은 검토 중 `#B26A00`에서 `#8A5200`으로 조정했습니다. `#B26A00`은 흰 배경에서 4.24:1로
> 일반 텍스트 AA에 미달합니다.

### 1.3 제보 상태 색 (도메인)

상태 값(`OPEN` / `IN_PROGRESS` / `RESOLVED`)은 변경하지 않습니다. 표현만 정합니다.

| 상태 | 라벨 | 채움 | 텍스트 | 대비 |
| --- | --- | --- | --- | --- |
| `OPEN` | 접수됨 | `#F2EFEA` | `#4A443C` | 8.39:1 |
| `IN_PROGRESS` | 처리중 | `#FBF0DC` | `#7A4A00` | 6.63:1 |
| `RESOLVED` | 해결됨 | `#E3F2EA` | `#1F5C43` | 6.80:1 |

**변경점**: 현행은 `OPEN`을 빨강(`bg-red-100 text-red-700`)으로 칠합니다. 접수됨은 오류가 아니라
정상 진행의 첫 단계이므로 중성으로 바꿉니다. **`danger` 계열 빨강은 오류와 파괴적 행동에만 씁니다.**
세 상태는 중성 → 앰버 → 초록의 진행으로 읽힙니다.

**색만으로 상태를 구분하지 않습니다.** 상태 칩은 항상 읽을 수 있는 한글 라벨을 함께 표시합니다.

### 1.4 카테고리 색

카테고리(소음·쓰레기·시설물·교통·기타)에는 **고유 색을 배정하지 않습니다.** 카테고리는 텍스트 칩으로만
표현합니다. 5개 카테고리 × 3개 상태에 각각 색을 주면 카드에서 상태 신호가 묻힙니다.

## 2. 타이포그래피

### 2.1 글꼴

```
--font-sans: "Pretendard Variable", -apple-system, BlinkMacSystemFont,
             "Apple SD Gothic Neo", system-ui, sans-serif;
```

- Pretendard Variable을 `next/font/local`로 셀프호스팅합니다. woff2 subset을 사용하고
  `display: swap`, `preload: true`로 지정합니다.
- 본문·제목·숫자·영문 모두 같은 패밀리를 씁니다. 별도 디스플레이 서체를 도입하지 않습니다.
- fallback은 지정하되, **fallback에 의존한 렌더링을 정상 상태로 보지 않습니다** (이슈 #15).

### 2.2 타입 스케일

한글 본문 기준으로 행간을 넉넉히 잡습니다. 자간은 제목에서만 음수를 씁니다 —
한글 본문에 양의 자간을 주지 않습니다.

| 역할 | 데스크톱 | 모바일 | 굵기 | 자간 | 용도 |
| --- | --- | --- | --- | --- | --- |
| `display` | 32 / 42 | 26 / 36 | 700 | -0.02em | 홈 히어로 |
| `h1` | 24 / 34 | 22 / 32 | 700 | -0.02em | 페이지 제목, 제보 상세 제목 |
| `h2` | 20 / 30 | 19 / 28 | 700 | -0.01em | 섹션 제목 |
| `h3` | 17 / 26 | 16 / 25 | 600 | -0.01em | 카드 제목, 서브섹션 |
| `body-lg` | 16 / 27 | 16 / 27 | 400 | 0 | 제보 본문 |
| `body` | 15 / 25 | 15 / 25 | 400 | 0 | 기본 본문 |
| `body-sm` | 13 / 21 | 13 / 21 | 400 | 0 | 카드 설명, 보조 문구 |
| `label` | 13 / 18 | 13 / 18 | 600 | 0 | 폼 label, 칩 |
| `caption` | 12 / 18 | 12 / 18 | 400 | 0 | 메타데이터, 시각 |

### 2.3 규칙

- 페이지당 `h1`은 하나입니다. 제목 레벨을 시각적 크기를 맞추려고 건너뛰지 않습니다 —
  크기가 필요하면 타입 역할 클래스를 쓰고 시맨틱 레벨은 유지합니다.
- **모바일 입력 필드의 글자 크기는 16px 이상**입니다 (iOS 자동 확대 방지). 현행 규칙을 유지합니다.
- 한글 줄바꿈: 제목·짧은 문구에 `word-break: keep-all`을 적용해 낱말 중간 끊김을 막습니다.
- 카드 제목은 2줄, 카드 설명은 2줄에서 말줄임합니다. 상세 화면 본문은 말줄임하지 않습니다.

## 3. 공간·형태·깊이·모션

### 3.1 Spacing

4px 배수 스케일만 씁니다: `2, 4, 8, 12, 16, 20, 24, 32, 40, 48, 64`.
임의값(`p-[13px]`)은 쓰지 않습니다.

| 맥락 | 값 |
| --- | --- |
| 페이지 좌우 여백 | 모바일 16, 태블릿 24, 데스크톱 32 |
| 콘텐츠 최대 폭 | 1280 (홈·목록), 768 (제보 상세 본문 칼럼) |
| 섹션 간격 | 모바일 32, 데스크톱 48 |
| 카드 내부 패딩 | 16 |
| 카드 그리드 간격 | 모바일 12, 데스크톱 20 |
| 폼 필드 간격 | 16 |
| 인접 터치 타깃 간격 | 최소 8 |

### 3.2 Radius

| 토큰 | 값 | 적용 |
| --- | --- | --- |
| `radius-sm` | 6px | 뱃지, 작은 태그 |
| `radius-md` | 10px | 버튼, 입력, 셀렉트 |
| `radius-lg` | 14px | 카드, 패널 |
| `radius-xl` | 20px | 모달, 바텀시트 |
| `radius-full` | 9999px | 칩, 아바타, 아이콘 버튼 |

### 3.3 Elevation

그림자는 4단계뿐입니다. 같은 층에 있는 요소에 서로 다른 그림자를 쓰지 않습니다.

| 토큰 | 값 | 적용 |
| --- | --- | --- |
| `elevation-0` | none (+ `border`) | 기본 카드, 목록 아이템 |
| `elevation-1` | `0 1px 2px rgba(26,24,21,.06), 0 1px 3px rgba(26,24,21,.04)` | 헤더(스크롤 시), 카드 hover |
| `elevation-2` | `0 4px 12px rgba(26,24,21,.08)` | 드롭다운, 팝오버, 지도 위 컨트롤 |
| `elevation-3` | `0 12px 32px rgba(26,24,21,.14)` | 모달, 바텀시트 |

### 3.4 Motion

| 토큰 | 값 |
| --- | --- |
| `duration-fast` | 120ms |
| `duration-base` | 180ms |
| `duration-slow` | 260ms |
| `ease-standard` | `cubic-bezier(.2, 0, 0, 1)` |
| `ease-exit` | `cubic-bezier(.4, 0, 1, 1)` |

- 애니메이션은 `transform`과 `opacity`, 색상에만 겁니다. 높이·폭·여백은 애니메이션하지 않습니다.
- 목록 항목에 등장 애니메이션을 걸지 않습니다 — 조회 결과가 갱신될 때 화면이 출렁입니다.
- `prefers-reduced-motion: reduce`에서 모든 duration을 0으로 내리고 위치 이동 효과를 제거합니다.
  상태 전달은 색·텍스트로 남깁니다.

### 3.5 Focus

- **모든** 인터랙티브 요소에 보이는 포커스 표시가 있습니다. `outline: none`만 두는 코드를 금지합니다.
- 포커스 링: `outline: 2px solid var(--ring); outline-offset: 2px;` — `:focus-visible`에만 적용합니다.
- `brand` 배경 위 요소는 `outline-color: var(--surface)`로 뒤집어 링이 보이게 합니다.
- 모달·드롭다운은 열릴 때 첫 인터랙티브 요소로 포커스를 옮기고, 닫을 때 여닫은 요소로 되돌립니다.

### 3.6 Disabled

- `opacity`로 비활성을 표현하지 않습니다 — 대비가 예측 불가능해집니다.
- 비활성 상태: 배경 `surface-muted`, 텍스트 `muted-foreground`, 경계 `border`,
  `cursor: not-allowed`, `aria-disabled="true"`.
- 비활성 이유를 사용자가 알 수 없는 경우, 비활성 대신 활성 상태로 두고 눌렀을 때 이유를 안내합니다.

### 3.7 터치 타깃

- 모바일에서 모든 인터랙티브 요소의 **히트 영역은 최소 44×44 CSS px**입니다.
  시각적 크기는 더 작아도 되며, 패딩이나 `::after` 확장으로 히트 영역을 채웁니다.
- 인접 타깃 사이 간격 최소 8px.
- 화면 하단에 고정되는 요소는 `padding-bottom: calc(16px + env(safe-area-inset-bottom))`를 씁니다.

## 4. 컴포넌트 anatomy

공통 원자는 `Ui` 접두사를 유지합니다. 아래는 **사용자에게 보이는 계약**이며 구현 분해 방식은 자유입니다.

### 4.1 Button (`UiButton`)

**구조**: `[선행 아이콘] 라벨 [후행 아이콘]` — 아이콘은 선택, 라벨은 필수(아이콘 전용 제외).

| Variant | 용도 | 채움 / 텍스트 / 경계 |
| --- | --- | --- |
| `primary` | 화면당 주요 행동 1개 | `brand` / `brand-foreground` / 없음 |
| `secondary` | 보조 행동 | `surface` / `foreground` / `border-strong` |
| `ghost` | 밀도 높은 영역, 헤더 | 투명 / `foreground` / 없음 (hover 시 `surface-muted`) |
| `danger` | 삭제 등 되돌릴 수 없는 행동 | `danger` / `#FFFFFF` / 없음 |

| Size | 높이 | 좌우 패딩 | 타입 |
| --- | --- | --- | --- |
| `sm` | 36 (모바일 히트 44) | 12 | `label` |
| `md` | 44 | 16 | `body-sm` 600 |
| `lg` | 52 | 20 | `body` 600 |

**규칙**
- 화면당 `primary`는 하나입니다. 나란한 두 버튼이 모두 `primary`일 수 없습니다.
- 아이콘 전용 버튼은 반드시 접근 가능한 이름을 가집니다 (`aria-label`).
- 진행 중 상태: 버튼 폭을 유지한 채 라벨을 유지하고 스피너를 앞에 붙입니다. **폭이 변하면 안 됩니다.**
- 링크로 이동하는 행동은 `<button>`이 아니라 `<a>`/`<Link>`입니다.

### 4.2 Input (`UiInput`)

**구조**: `label(항상 표시) → 입력 상자 → 도움말 또는 오류`

- label은 항상 보입니다. placeholder를 label 대신 쓰지 않습니다.
- 상자: 높이 44, 패딩 12, `radius-md`, 경계 `border-strong`, 배경 `surface`.
- 포커스: 경계 `brand` + 포커스 링.
- 오류: 경계 `danger`, 아래에 `danger` 색 메시지, `aria-invalid="true"`,
  `aria-describedby`로 메시지와 연결.
- 오류 메시지는 무엇이 잘못됐고 어떻게 고치는지 씁니다. "입력값이 올바르지 않습니다"만 두지 않습니다.
- 필수 표시는 `*`가 아니라 선택 항목에 "(선택)"을 붙이는 방식을 씁니다.

### 4.3 Chip

카테고리 필터, 상태 필터, 상태 표시에 쓰는 작은 단위입니다.

| 종류 | 상호작용 | 형태 |
| --- | --- | --- |
| `filter` | 누를 수 있음 | 높이 36(히트 44), `radius-full`, 미선택 `surface`+`border`, 선택 `brand-subtle`+`brand` 텍스트+`brand` 경계 |
| `status` | 표시 전용 | 높이 24, `radius-sm`, §1.3 색, `label` 타입 |
| `category` | 표시 전용 | 높이 24, `radius-full`, `surface-muted`+`muted-foreground` |

**규칙**
- `filter` 칩 그룹은 단일 선택이면 `role="radiogroup"`, 다중이면 각각 `aria-pressed`를 씁니다.
- 모바일에서 칩 줄이 넘칠 때 **줄바꿈으로 고아 항목을 만들지 않고 가로 스크롤**합니다.
  스크롤 컨테이너는 키보드 포커스가 닿을 때 해당 칩이 보이도록 스크롤합니다.
- 가로 스크롤 영역의 오른쪽 끝에는 더 있음을 알리는 페이드를 둡니다.

### 4.4 Card (`UiCard`)

- 기본: 배경 `surface`, 경계 `border`, `radius-lg`, `elevation-0`, 패딩 16.
- 클릭 가능한 카드는 **카드 전체가 하나의 링크**입니다. `onClick`이 붙은 `div`를 쓰지 않습니다.
- hover: `elevation-1` + 경계 `border-strong`. focus-visible: 포커스 링.
  pressed: 배경 `surface-muted`.
- 카드 안에 별도 행동(공감 등)을 둘 경우 링크 안에 버튼을 중첩하지 않습니다 —
  카드 표면을 덮는 `::after` 링크 + 그 위에 `position: relative`인 행동 버튼 방식을 씁니다.

### 4.5 Modal (`UiDialog`)

- 뒤 배경 `scrim`, 패널 `surface`, `radius-xl`, `elevation-3`.
- 데스크톱: 화면 중앙, 최대 폭 480(폼)/640(내용).
- 모바일: 화면 하단에서 올라오는 시트, 상단만 `radius-xl`, 최대 높이 `90dvh`, 내부 스크롤.
- 필수: focus trap, Escape 닫기, 이름이 있는 닫기 버튼, `aria-labelledby`로 제목 연결,
  닫힐 때 포커스 복귀.
- 파괴적 확인 다이얼로그: 초기 포커스는 **취소**에 둡니다. 확인 버튼은 `danger` variant이며
  라벨에 대상을 씁니다("삭제" 대신 "제보 삭제").

### 4.6 Empty state

**구조**: `아이콘(선택) → 제목 → 한 문장 설명 → 주요 행동 [→ 보조 행동]`

- 제목은 무슨 일이 일어났는지, 설명은 다음에 무엇을 할 수 있는지 씁니다.
- **빈 상태는 오류가 아닙니다.** `danger` 색을 쓰지 않습니다. 아이콘은 `muted-foreground`.
- 서로 다른 빈 맥락은 서로 다른 문구를 가집니다: "이 지역에 제보 없음"과
  "검색 결과 없음"과 "작성한 제보 없음"은 같은 화면이 아닙니다.

### 4.7 Error state

**구조**: `제목 → 사용자 언어 설명 → 복구 행동 [→ 보조 경로]`

- 내부 기술 용어를 사용자에게 노출하지 않습니다 — "Kakao SDK 로딩 실패", 환경 변수 이름,
  HTTP 상태 코드, 스택 트레이스 금지. 기술 상세는 개발 로그로 보냅니다.
- 복구 행동은 항상 있습니다: 재시도, 또는 다른 경로.
- **오류 범위는 실패한 영역에만 적용합니다.** 지도가 실패했다고 홈 전체를 오류 화면으로
  바꾸지 않습니다 (이슈 #20).
- 크기: 인라인(영역 안), 섹션, 페이지 세 단계. 영역 실패는 인라인·섹션까지만 커집니다.

### 4.8 Skeleton

- 실제 콘텐츠와 **같은 파일, 같은 레이아웃 프리미티브**를 공유합니다 (ADR-0009).
  구조를 복제한 별도 컴포넌트를 만들지 않습니다.
- 색: `surface-muted`. 셰이머는 `prefers-reduced-motion`에서 정지합니다.
- 스켈레톤의 블록 개수·크기는 실제 콘텐츠의 평균과 같아야 합니다 — 로드 후 레이아웃이 점프하지 않게 합니다.
- 텍스트 블록은 마지막 줄을 짧게(60~70%) 그립니다.
- 스켈레톤이 표시되는 영역은 `aria-busy="true"`이며, 완료 시 결과 건수를 알립니다.

## 6. 조회 계약이 레이아웃에 남기는 제약

ADR-0007 / ADR-0003 / `CONTEXT.md`의 도메인 의미는 이 계약에서 **변경하지 않습니다.**
레이아웃은 다음을 반드시 지킵니다.

1. **영역 조회는 명시적 사용자 의도로만 실행됩니다.**
   - 지도 드래그·확대/축소는 dirty 표시만 남깁니다.
   - dirty일 때 지도 영역 안에 **"이 지역 재검색"** 버튼이 나타납니다.
     위치는 지도 하단 중앙, `elevation-2`, 히트 영역 44px 이상, 키보드로 도달 가능.
   - 이 버튼이 dirty 상태를 해소하는 유일한 지도 내 수단입니다.
   - 모바일 피드/지도 모드 전환은 조회를 실행하지 않습니다.

2. **내 동네는 기본 컨텍스트이며 지도 초점과 분리됩니다.**
   - 내 동네를 필터 칩·토글·스코프 셀렉터로 그리지 않습니다.
   - 헤더의 동네 표시는 현재 기본 컨텍스트의 **표시**이며, 누르면 내 동네 설정을 엽니다.
   - "내 동네로 돌아가기"는 지도 초점을 바꾸는 행동이고, 그 결과로 영역 조회가 커밋됩니다.
     지도가 내 동네에서 멀어졌을 때만 나타납니다.

3. **선택 지점은 지도 초점과 다른 것으로 보여야 합니다.**
   - 제보 작성 화면의 지도는 홈 지도와 시각적으로 구분됩니다: 중앙 크로스헤어 +
     하단에 선택된 주소를 확인하는 바.
   - 홈 지도에는 크로스헤어를 그리지 않습니다.

4. **근접 그룹은 카카오 클러스터와 다르게 보입니다** (ADR-0008).
   - 근접 그룹 마커: 건수 배지가 붙은 핀. 눌러도 팝업을 띄우지 않고 선택 지점 섹션에 멤버를 나열합니다.
   - 클러스터: 원형 카운트. 누르면 확대합니다.

```
├─────────────────────────────────────────────────────┤

│  지도  높이 clamp(400px, 46vh, 480px)               │
│        ├ 좌상단: 현재 탐색 컨텍스트 라벨             │
│        ├ 우상단: 내 동네로 돌아가기 (조건부)         │

│  └─────────┘ └─────────┘ └─────────┘                │
└─────────────────────────────────────────────────────┘
```

- 콘텐츠 최대 폭 1280, 좌우 여백 32.
- **지도 높이는 1440×900 첫 화면에서 첫 카드 행의 상단이 보이도록** 제한합니다.
  지도가 목록의 존재를 가리면 안 됩니다.
- 카드 열: `wide` 3열, `desktop` 3열, `tablet` 2열, `mobile` 1열.
- 선택 지점 섹션(마커/근접 그룹 선택)은 지도 바로 아래, 목록 위에 삽입됩니다.

### 7.3 홈 — 모바일 (390px)

**기본 진입 화면은 제보 피드입니다.** 지도는 명시적 전환으로 엽니다.

```
┌───── 헤더 56px (sticky) ─────┐
│ 로고        [제보]  [메뉴]   │
├──────────────────────────────┤
│ 컨텍스트 라벨   [피드|지도]  │   ← 세그먼트 전환
├──────────────────────────────┤
│ 검색                          │
├──────────────────────────────┤
│ [전체][소음][쓰레기]…  →      │   ← 가로 스크롤
├──────────────────────────────┤
│ 제보 N건                      │
│ ┌──────────────────────────┐ │
│ │ 카드 (1열)               │ │
│ └──────────────────────────┘ │
│ …                            │
└──────────────────────────────┘
      [ 제보하기 ] ← 하단 고정, safe-area
```

- 390×844 첫 화면 안에 **현재 탐색 컨텍스트 + 필터 + 최소 한 개의 핵심 행동**이 보입니다.
- 지도 모드로 전환하면 지도가 `100dvh - 헤더 - 전환바`를 차지합니다.
  고정 450px 패널이 콘텐츠를 밀어내는 현행 구조를 쓰지 않습니다.
- 세그먼트 전환은 `role="tablist"`이며 선택 상태를 보조기술이 인식합니다.
- 하단 고정 제보하기 CTA는 마지막 카드를 가리지 않도록 목록 하단에 CTA 높이만큼 여백을 둡니다.

### 7.4 그 외 화면

| 화면 | 데스크톱 | 모바일 |

| 제보 상세 | 본문 칼럼 최대 768 중앙, 위치·지도는 본문 아래 보조 섹션 | 제목·상태·시각이 첫 화면에 보이고, 지도는 본문 아래 240px 이하 |

## 8. 상태 표현 계약

각 상태는 **서로 구분되는 화면**을 가집니다. 합치지 않습니다.

| 상태 | 표현 | 복구 행동 |
| --- | --- | --- |
| 인증 초기화 중 | 스켈레톤 | 없음 (익명·오류 화면을 순간 노출하지 않음) |
| 익명 (보호 화면 접근) | 로그인 필요 이유 + 로그인 CTA + 홈으로 | 로그인 성공 후 원래 화면 복귀 |
| 데이터 로딩 | 해당 화면 구조의 스켈레톤 | 없음 |
| 정상 (결과 있음) | 콘텐츠 | — |
| 정상 (제보 0건) | Empty state | 첫 제보 작성 / 탐색 범위 바꾸기 |
| 검색 결과 0건 | Empty state (문구 다름) | 검색어 지우기 |
| 제보 조회 실패 | Error state (목록 영역) | 다시 시도 (검색어·카테고리·마지막 커밋 영역 보존) |
| 지도 초기화 중 | 최종 지도 크기와 같은 placeholder | 없음 |
| 지도 초기화 실패 | 축소된 인라인 안내 (모바일은 접힌 높이) | 지도 다시 시도 — **피드는 계속 동작** |
| 프로필 미생성 | 프로필 만들기 안내 | 프로필 설정 |
| 프로필 조회 실패 | Error state | 다시 시도 |

**지도 실패와 데이터 실패는 별개입니다.** 각각 독립적인 재시도를 가집니다.

**공지 규칙**: 상태 변화는 텍스트로도 전달합니다. 조회 완료 시 결과 건수를 `aria-live="polite"`로
한 번 알리고, 같은 내용을 반복 공지하지 않습니다.

## 10. 미결정 항목 (후속 이슈로 이월)

이 계약에서 확정하지 **않은** 것들입니다. 구현자는 이 항목을 임의로 결정하지 말고 이슈를 만듭니다.

1. **다크 모드** — v2는 라이트 전용입니다. `globals.css`의 기존 `.dark` 블록은 지원 계약이 아닙니다.
   다크 토큰 세트와 지도 타일 대응을 별도 이슈로 다룹니다.
2. **관리자 셸 재설계** — 사이드바 구조·정보 밀도까지만 정했고 화면별 레이아웃은 미정입니다.
3. **일러스트레이션 / 빈 상태 아트** — 현재는 아이콘만 씁니다. 로고 캐릭터를 빈 상태에 활용할지 미정.
4. **로고 반응형 변형** — 모바일에서 워드마크 대신 핀 심볼만 쓸지, 심볼 SVG를 새로 만들지 미정.

5. **온보딩 / 최초 진입 안내** — 내 동네를 아직 설정하지 않은 신규 주민의 첫 경험.
6. **제보 작성 화면 전체 레이아웃** — 선택 지점의 시각 구분(§6.3)만 정했고 폼 단계 구성은 미정.
7. **알림 / 토스트 체계** — 현재 `react-hot-toast`를 씁니다. 토큰화와 위치·중복 정책 미정.
8. **Pretendard subset 범위와 용량 예산** — 어떤 유니코드 블록을 포함할지, 폰트 예산 상한 미정.
