# UI v2 레퍼런스 레이아웃

_Status: 검토 대기 (이슈 #14) · Last verified: 2026-08-13_

[`UI_V2_CONTRACT.md`](./UI_V2_CONTRACT.md)의 토큰·컴포넌트 계약을 실제 화면에 적용한 레퍼런스입니다.
데스크톱은 **1440×900**, 모바일은 **390×844**를 기준으로 합니다.

와이어프레임은 구조·위계·상태를 고정하기 위한 것입니다. 픽셀 단위 재현이 목적이 아니며,
치수가 적힌 곳은 계약이고 적히지 않은 곳은 구현 재량입니다.

범례: `▓` 이미지/지도 영역 · `▭` 스켈레톤 블록 · `(조건부)` 조건이 맞을 때만 렌더

## 2. 홈 — 피드 상태 (목록 중심)

지도를 열지 않은 채 목록만 탐색하는 상태입니다.

### 2.1 데스크톱 1440

지도 섹션은 유지되고 목록만 갱신됩니다. 별도 레이아웃이 없습니다 — §1.1과 동일하되,
검색·카테고리 변경 시 다음이 바뀝니다.

```
│  '가로수길' 검색 결과 · 제보 7건    [ ✕ 검색 지우기 ]   [전체][소음]…  │
```

- 검색 결과 상태에서는 섹션 제목이 검색어를 포함하고, 검색 해제 행동이 나란히 옵니다.
- 카테고리 변경은 **명시적 사용자 의도**이므로 영역 조회를 커밋합니다.

### 2.2 모바일 390

§1.2와 동일합니다. 모바일의 기본 상태가 곧 피드 상태입니다.

```

│                                                                    24  │
│  ┌──────────────────────────────────────────────────────────────────┐  │
│  │ 📍 성수동 카페거리                                          [ ✕ ] │  │ 선택 지점
│  │ 이 지점의 제보 3건                                                │  │ 섹션
│  │ ┌────────────┐ ┌────────────┐ ┌────────────┐                     │  │
```

- 선택 지점 섹션은 지도 바로 아래, 전체 목록 위에 들어갑니다.

- 닫기 버튼은 이름이 있고(`aria-label="선택 해제"`), 닫으면 지도의 선택 강조도 함께 풀립니다.

**빈 상태 문구는 맥락마다 다릅니다 — 합치지 않습니다.**

| 맥락 | 제목 | 설명 | 주요 행동 |
| --- | --- | --- | --- |
| 영역에 제보 0건 | 이 지역에는 아직 제보가 없어요 | 첫 번째 제보를 남기거나 지도를 옮겨 다른 곳을 살펴보세요 | 제보하기 |
| 검색 결과 0건 | '가로수길' 검색 결과가 없어요 | 다른 검색어를 써보거나 카테고리 필터를 해제해보세요 | 검색 지우기 |
| 카테고리 필터로 0건 | 이 카테고리에는 제보가 없어요 | 전체 보기로 돌아가면 다른 제보를 볼 수 있어요 | 전체 보기 |
| 내 제보 0건 | 아직 작성한 제보가 없어요 | 동네에서 발견한 일을 이웃에게 알려보세요 | 제보하기 |

## 5. 지도 오류 상태

**지도 실패가 제보 피드를 오류 화면으로 바꾸지 않습니다.**

### 5.1 데스크톱 1440

```
│  ┌──────────────────────────────────────────────────────────────────┐  │
│  │                                                                   │  │
│  │                            🗺️                                     │  │ 지도 영역
│  │              지금은 지도를 표시할 수 없어요                       │  │ 안에서만
│  │        아래 제보 목록은 그대로 확인할 수 있어요                   │  │ h 240
│  │                    [ 지도 다시 시도 ]                             │  │
│  │                                                                   │  │
│  └──────────────────────────────────────────────────────────────────┘  │
│                                                                    48  │
│  제보 24건                    [전체][소음]…      ← 정상 동작            │
│  ┌────────────────┐  ┌────────────────┐  ┌────────────────┐            │
│  │     카드       │  │     카드       │  │     카드       │            │
```

- 지도 오류 블록은 정상 지도 높이보다 **낮게**(240px) 그려 목록을 위로 끌어올립니다.
- 검색·카테고리·제보하기는 계속 동작합니다.

### 5.2 모바일 390

```
├──────────────────────────────┤
│ 성수2가1동 주변  [ 피드 |지도 ]│
├──────────────────────────────┤
│ ┌──────────────────────────┐ │
│ │ 🗺️ 지금은 지도를 표시할   │ │ 접힌 안내
│ │    수 없어요   [다시 시도]│ │ h ≤ 88
│ └──────────────────────────┘ │
├──────────────────────────────┤
│ [전체][소음][쓰레기]→        │ ← 밀려나지 않음
│ 제보 24건                     │
│ ┌──────────────────────────┐ │
│ │ 카드                      │ │
```

**계약**
- 사용자 문구에 `Kakao`, `SDK`, 환경 변수 이름, HTTP 상태 코드가 등장하지 않습니다.
- 재시도는 **지도 초기화만** 다시 실행합니다. 검색어·카테고리·마지막 커밋 영역을 보존합니다.
- 지도 실패와 제보 조회 실패는 서로 다른 블록에 서로 다른 재시도를 가집니다.
- 오류 등장은 `aria-live="polite"`로 한 번만 공지하고 재시도마다 반복 공지하지 않습니다.

### 5.3 제보 조회 실패 (지도는 정상)

```
│  ┌──────────────────────────────────────────────────────────────────┐  │
│  │ ⚠️  제보를 불러오지 못했어요                                      │  │ danger 텍스트
│  │     잠시 후 다시 시도해주세요             [ 다시 시도 ]           │  │ 목록 영역만
│  └──────────────────────────────────────────────────────────────────┘  │
```

지도와 검색 바는 그대로 남습니다. 페이지 전체를 교체하지 않습니다.

## 7. 제보 카드 anatomy

```
┌──────────────────────────────────────┐  카드 전체가 하나의 <a>
│ [접수됨]                 🔧 시설물  │  ① 상태 + 카테고리, 같은 행
│ 도로에 큰 웅덩이가 생겼습니다         │  ② 제목    h3, 최대 2줄 말줄임
│                                      │
│ 비 온 뒤부터 물이 고여 있어  ┌─────┐ │  ③ 콘텐츠 미리보기, 최소 높이 96
│ 보행자가 지나가기 어렵습니다  │사진 │ │     본문 최대 3줄 + 선택적 96px 썸네일
│                               └─────┘ │
│ ────────────────────────────────────  │
│ 📍 성수2가1동                         │  ④ 위치 caption
│ 1시간 전                ♡ 12   💬 3   │  ⑤ 시각 + 반응 caption
└──────────────────────────────────────┘
```

**스캔 순서**: 상태·카테고리 → 제목 → 설명 → 위치 → 시각 → 공감·댓글.
DOM 순서도 같습니다 — 보조기술이 읽는 순서와 눈으로 훑는 순서를 어긋나게 두지 않습니다.

**콘텐츠 미리보기 정책 — 본문 우선, 이미지는 보조**

| 경우 | 표현 |
| --- | --- |
| 이미지 있음 | 본문 3줄 옆에 96×96 `object-cover` 썸네일을 둡니다. 이미지는 보조 정보입니다 |
| 이미지 없음 | 큰 빈 면·대체 배경을 그리지 않고 본문이 전체 폭을 씁니다 |
| 이미지 로드 실패 | 썸네일만 제거하고 본문이 전체 폭을 회복합니다. alt 텍스트와 깨진 아이콘을 노출하지 않습니다 |

**왜 16:9 슬롯을 없앴는가**: 이미지 없는 제보가 많은 목록에서 큰 회색 면은 카드의 절반을
차지하면서도 정보를 주지 못했습니다. 짧은 본문이 그 안에 떠 있어 여전히 빈 미디어 슬롯처럼
보였고, 첫 화면에 탐색 가능한 카드 수도 줄였습니다. 본문은 항상 같은 자리에 두고 이미지만 작은
썸네일로 붙이면 제보 간 비교가 빨라지고 이미지 부재를 별도 상태로 그리지 않아도 됩니다.

```
사진 있음                          사진 없음
┌──────────────────────┐          ┌──────────────────────┐
│ [처리중]       시설물 │          │ [접수됨]          소음│
│ 도로에 큰 웅덩이가…   │          │ 밤마다 공사 소음이…   │
│ 비 온 뒤부터 물이 [사진]│          │ 밤 11시가 넘어도   │
│ 고여 있어…       96px │          │ 공사 소리가 계속…  │
│ ──────────────────── │          │ ──────────────────── │
│ 📍 성수2가1동        │          │ 📍 성수2가1동        │
│ 1시간 전   ♡ 12 💬 3 │          │ 2시간 전   ♡ 4  💬 1 │
└──────────────────────┘          └──────────────────────┘
```

**본문은 한 카드에 한 번만, 최대 3줄로 나옵니다.** 이미지 로드 실패는 본문을 옮기거나
복제하지 않고 썸네일 유무만 바꿉니다.

같은 그리드 행의 카드는 `h-full`과 제목·미리보기 최소 높이로 같은 높이를 유지합니다.

**상태별 표현**

| 상태 | hover | focus-visible | pressed |
| --- | --- | --- | --- |
| 표현 | `elevation-1` + 경계 `border-strong` | 포커스 링 2px `ring` + offset 2 | 배경 `surface-muted` |

**스켈레톤** — 같은 파일, 같은 프리미티브 (ADR-0009)

```
┌──────────────────────────────────────┐
│ ▭▭▭▭                                  │  상태 칩 자리
│ ▭▭▭▭▭▭▭▭▭▭▭▭▭▭▭▭▭▭▭                  │  제목
│ ▭▭▭▭▭▭▭▭▭▭▭▭▭▭▭▭▭▭▭▭▭▭▭             │  본문 1줄
│ ▭▭▭▭▭▭▭▭▭▭▭▭▭▭▭▭▭▭▭▭▭▭▭             │  본문 2줄
│ ▭▭▭▭▭▭▭▭▭▭▭▭▭▭ (60%)                 │  본문 마지막 줄 짧게
│ ────────────────────────────────────  │
│ ▭▭▭▭▭▭▭▭▭                             │  위치
│ ▭▭▭▭▭▭                 ▭▭▭   ▭▭▭    │  시각 + 반응
└──────────────────────────────────────┘
```

실제 카드와 스켈레톤은 `REPORT_CARD_REGIONS`의 같은 구역 이름을 공유하고,
한쪽에만 구역이 생기면 계약 테스트가 깨집니다.

**그리드 리듬**: 모바일 1열 gap 12 · 태블릿 2열 gap 16 · 데스크톱 3열 gap 20.

**카드 내부 행동을 둘 경우**: 카드 표면을 덮는 `::after` 링크 + 그 위에 `position: relative`인
버튼을 둡니다. `<a>` 안에 `<button>`을 중첩하지 않습니다.

### 9.3 삭제 확인 다이얼로그

```
        ┌─────────────────────────────────────────┐ 최대 폭 480
        │  제보를 삭제할까요?                      │ aria-labelledby
        │  삭제한 제보와 댓글은 되돌릴 수 없어요.  │
        │                                         │
        │              [ 취소 ]  [ 제보 삭제 ]    │
        │               ↑초기 포커스   danger      │
        └─────────────────────────────────────────┘
```

- 초기 포커스는 **취소**입니다. Escape로 닫히고, 닫히면 삭제 버튼으로 포커스가 돌아옵니다.
- 확인 버튼 라벨에 대상이 들어갑니다: "확인"이 아니라 "제보 삭제".

### 9.4 상세 스켈레톤

실제 화면의 ①~⑧ 구역을 같은 순서·같은 크기로 그립니다 (ADR-0009).
지도 자리에는 240px 높이 블록을 둬서 로드 후 점프를 없앱니다.
